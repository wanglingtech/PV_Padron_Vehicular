RECOMENDADO

Respaldo JSON Universal (.json)

Exporta una copia íntegra con metadatos, firmas de tiempo y resumen de registros de las 15 tablas. Ideal para copias de seguridad periódicas y restauración en un solo clic dentro del sistema.

Incluye vehículos, personas, pólizas, revisiones, trámites y usuarios.
Compatible con restauración modo Fusión (Merge) o Reemplazo total.
Portátil e independiente de versiones de base de datos.
MIGRACIÓN MULTI-BD

Script SQL Portátil (.sql)

Genera un script SQL ANSI estándar completo con CREATE TABLE IF NOT EXISTS e INSERT INTO ... ON CONFLICT DO NOTHING listo para ejecutarse en cualquier motor relacional.

Compatible con PostgreSQL, Supabase, Neon, AWS RDS, GCP Cloud SQL.
Estructurado en orden estricto de claves foráneas para evitar fallos.
Escapado seguro de valores y caracteres especiales en UTF-8.
